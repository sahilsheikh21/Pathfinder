## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| user keyboard input to selection/execution | Untrusted key and query input control which command is selected and executed |
| overlay component to command callback | UI selection invokes action callbacks that can change browser state |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-04 | T | src/renderer/components/CommandPalette.tsx | mitigate | Bind execution to selected command object from static ranked list, not free-form evaluated strings |
| T-04-05 | D | src/renderer/components/CommandPalette.tsx | mitigate | Clamp selection index and handle empty results to prevent runtime crashes under rapid key events |
| T-04-06 | I | src/renderer/styles/global.css | accept | Styling metadata is non-sensitive and does not expose private runtime state |
