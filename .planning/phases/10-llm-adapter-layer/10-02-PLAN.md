| Boundary | Description |
|----------|-------------|
| main process to provider SDK/network | External SDK and network failures can leak sensitive details unless normalized/redacted |
| local persistence to disk | Secret/config writes can expose credentials if storage separation is violated |

| T-10-07 | D | src/main/llm/llmAdapterService.ts | mitigate | Apply bounded timeouts and fail-fast error mapping to prevent hanging requests |
| T-10-08 | R | src/main/llm/llmAdapterService.ts | mitigate | Return typed provider/error metadata for deterministic diagnostics without secret leakage |
