| Boundary | Description |
|----------|-------------|
| renderer -> main live-agent control IPC | Untrusted run requests and approval actions cross into privileged orchestration code |
| model-proposed steps -> executable actions | Untrusted step proposals can mutate external state if not gated |

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-13-01 | E | src/main/liveAgentOrchestrator.ts | mitigate | Enforce high-impact gate before execution and keep approval checks in main process only |
| T-13-02 | T | src/main/liveAgentRiskPolicy.ts | mitigate | Use deterministic rule-based risk classifier and default unknown mutation intents to high-impact |
| T-13-03 | D | src/main/liveAgentOrchestrator.ts | mitigate | Single active run guard + explicit cancel path to prevent concurrent orchestration contention |
| T-13-04 | I | src/main/main.ts IPC fallback paths | mitigate | Return redacted typed failure envelopes and avoid leaking internal stack details to renderer |
</threat_model>
