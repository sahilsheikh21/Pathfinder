<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| renderer to preload | Untrusted page-driven UI requests cross into privileged bridge |
| preload to main IPC | Renderer-originated requests cross into Electron main process |
| local machine to app config | User local state and settings can be modified outside runtime |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01 | E | src/main/main.ts | mitigate | Enforce contextIsolation true, nodeIntegration false, and sandbox true in BrowserWindow options |
| T-01-02 | T | src/preload/index.ts | mitigate | Expose minimal allowlisted API surface via contextBridge and avoid raw ipcRenderer export |
| T-01-03 | S | src/shared/ipc.ts | mitigate | Use fixed channel constants and typed request shapes to prevent arbitrary channel invocation |
| T-01-04 | R | src/main/main.ts | accept | Minimal scaffold phase has low-value operations only; add structured logging in later phase |
</threat_model>
